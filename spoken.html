Phase A privacy contract

Your audio, filenames and transcript text stay in this browser flow. Library metadata, progress, queue and listening statistics are stored locally. Browser object URLs are never persisted.

After a reload, local media is intentionally marked needs relink. Select the same file again and its deterministic metadata fingerprint restores the saved progress.

Timed WebVTT/SRT cues are validated before import. Plain text is readable but not seekable.
